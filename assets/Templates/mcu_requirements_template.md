| 参数 | 预设值 | 单位 | 作用 | 修改原因 |
| --- | --- | --- | --- | --- |
| `BOARD_HSE_HZ` | 8000000 | Hz | 外部晶振 | 按实际晶振修改 |
| `BOARD_VREF_MV` | 3300 | mV | ADC/DAC参考 | 按基准电压修改 |
| `ADC_INPUT_DIVIDER` | 1.0f | - | 输入分压比 | 按硬件电路修改 |
| `ADC_FRONTEND_GAIN` | 1.0f | - | 前端放大倍数 | 按运放电路修改 |
| `ADC_BIAS_MV` | 1650 | mV | 交流偏置 | 按偏置电路修改 |
| `ADC_SAMPLE_POINTS` | 128 | 点 | ADC DMA缓冲点数 | 按频率/精度修改 |
| `ADC_DMA_CHANNEL` | 待确认 | - | ADC DMA通道 | 按芯片手册和资源占用修改 |
| `DAC_OUTPUT_GAIN` | 1.0f | - | 输出比例 | 按输出级修改 |
| `DAC_DMA_CHANNEL` | 待确认 | - | 片上DAC输出DMA通道 | 按芯片手册和资源占用修改 |
| `DAC_OUTPUT_CHANNEL` | DAC1 | - | 片上DAC输出通道 | 按PA4/PA5硬件连接修改 |
| `PWM_ACTIVE_LEVEL` | 1 | - | PWM有效电平 | 按驱动电路修改 |
| `PWM_DMA_CHANNEL` | 待确认 | - | PWM更新CCR的DMA通道 | 按定时器通道修改 |
| `OLED_REFRESH_MS` | 200 | ms | 显示刷新 | 按体验修改 |
